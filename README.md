# BETWEEN WEATHER

날씨를 장소와 하루의 선택으로 연결하는 도시 생활 서비스입니다.

전국 17개 시도의 지금 날씨를 보여 주는 데서 끝나지 않고, **그 날씨에 가기 좋은 곳**을 골라 줍니다.
비가 오면 실내가, 더우면 물가와 그늘이, 맑고 선선하면 전망과 산책로가 위로 올라옵니다.

**바로 보기 →** `https://<깃허브 계정>.github.io/<저장소 이름>/`

## 화면

| 화면 | 하는 일 |
|---|---|
| **날씨** | 시도별 기온 지도, 지역 상세와 3시간 예보, 그 날씨에 맞는 장소 3곳 |
| **명소** | 전국 68곳을 지역·실내외·갈래로 걸러 보고 지금 날씨로 순위를 매긴다 |
| **저장** | 자주 보는 지역과 마음에 든 장소를 모아 한눈에 비교한다 |
| **가이드** | 우산·빨래·외출 지수를 계산하고 그 순간을 기록으로 남긴다 |
| **소개** | 서비스 설명 |

## 어떻게 고르는가

장소마다 "어떤 날씨에 강한가"를 적어 두고(실내 여부 · 비에 강함 · 더위 대피 · 바람에 약함),
지금 기온·강수·바람·구름과 맞춰 0~100점으로 환산합니다. 점수와 함께 **왜 그 순위인지**도 보여 줍니다.

명소 화면의 **날씨를 바꿔 보기**를 켜고 슬라이더를 움직이면, 목록이 그 자리에서 다시 정렬됩니다.

## 데이터

- **기상** — [Open-Meteo](https://open-meteo.com/) (키가 필요 없는 공개 API)
- **장소 사진·설명** — 위키백과 (CC BY-SA), 카드가 화면에 들어올 때만 내려받습니다
- **시도 경계** — 통계청 시도 경계(2018)를 단순화해 SVG 경로로 변환
- **회원·기록·준비물·내 장소** — 프로젝트에 포함된 Mock API. 정적 호스팅에서는
  같은 규칙을 브라우저에서 실행하고 `localStorage`에 남깁니다

## 실행

```bash
npm install
npm run dev       # http://localhost:3100
```

회원·기록·준비물처럼 서버가 필요한 기능까지 함께 보려면:

```bash
npm run dev:all   # 화면(3100) + API 서버(3001)
```

빌드와 검사:

```bash
npm run build
npm run lint
```

## 구조

```
src/
├─ api/            서버 통신 (기상 · 위키백과 · 회원 · 기록 · 장소)
│  └─ mockAdapter  정적 호스팅에서 API를 브라우저 안에서 처리
├─ components/     화면 조각 (카드 · 목차 · 상태 패널 · 지도 등)
├─ views/          라우터가 연결하는 화면
├─ stores/         Pinia (인증 · 저장한 지역과 장소 · 단위 설정)
├─ data/           시도 좌표 · 시도 경계 · 장소 목록 · 평년값
├─ utils/          추천 점수 · 생활지수 · 기온 색 · 화면 효과
└─ router/         라우트 정의와 접근 제한

mock-api/          Node로 띄우는 API 서버 (회원 · 기록 · 준비물 · 내 장소)
```

## 배포

`main`에 push하면 GitHub Actions가 빌드해 GitHub Pages로 올립니다.
정적 호스팅이라 서버가 없으므로, 회원·기록 같은 기능은 브라우저 안에서 같은 규칙으로 동작합니다.

## 사용 기술

Vue 3 (Composition API) · Vue Router · Pinia · Axios · Vite · Element Plus · SVG · Canvas
